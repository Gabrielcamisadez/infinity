- The homepage doesn’t have any obvious input fields. Let’s dig deeper.

Since the objective states that we have to exploit the SSRF and this page doesn't have any input field, let’s visit other pages. In http://54.166.141.194/index.html, we’ll find a form with some input fields.

The IP address http://169.254.169.254 is used in AWS to access instance metadata and user-data for an EC2 instance. This special IP address provides information about the instance, such as its IAM role, security credentials, and other metadata.

* Exploiting SSRF to Access EC2 Metadata

After a bit of trial & error, we’ll discover that the Company field is vulnerable to SSRF.

* Authorizing IAM Security Credentials
Now that we have finally obtained the security credentials i.e, AccessKeyId, SecretAccessKey, and Token, we can now authenticate with the AWS CLI & further enumerate the environment.

#+begin_src shell
